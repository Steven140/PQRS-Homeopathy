# PQRS Homeopathy
**Perfect Quick Reliable Safe**

## Project Overview
PQRS Homeopathy is an Android-based application developed as a group academic project by three Computer Engineering students.

The application aims to connect patients with homeopathic practitioners through a digital platform.

## Key Features
- Patient registration and login
- Doctor registration and login
- Patient information and medical history collection
- Symptom questionnaire
- Doctor consultation and prescription management
- Medicine ordering functionality

## Technologies Used
- **Programming Language:** Java
- **Platform:** Android
- **Database:** Firebase Realtime Database
- **Authentication:** Firebase Authentication

## Project Type
Bachelor of Engineering – Computer Engineering  
Group Project – 3 Members
