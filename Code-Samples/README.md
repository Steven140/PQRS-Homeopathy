# Programming Samples – PQRS Homeopathy

## Project Overview
PQRS Homeopathy (Perfect Quick Reliable Safe) is an Android application developed as a Bachelor’s final-year group project by three members. It was designed to connect patients with homeopathic practitioners through registration, consultation-related features, and medicine ordering.

## Programming Language and Technologies
- Java – Android application development
- Firebase Authentication – user registration and authentication
- Firebase Realtime Database – storing user information
- Android XML – user interface layouts

## Code Samples
The Java files in this folder are based on the programming excerpts printed in Chapter 6.2, “Working of the Project,” of the Bachelor’s project report.

1. `PatientRegistrationActivity.java` – patient registration using Firebase Authentication and Realtime Database.
2. `DoctorRegistrationActivity.java` – doctor registration using Firebase Authentication and Realtime Database.

## Source and Transcription Notes
The original complete Android Studio source-code project is not available in this submission. These samples have therefore been transcribed from the code excerpts included in the Bachelor’s project report.

Some lines in the printed report are incomplete or unclear. Where the report does not provide enough information, the missing implementation has not been presented as verified original code. Comments identify relevant gaps, and any reconstructed portions should be interpreted as transcription clarifications rather than a complete original implementation.

These files are submitted as supporting programming samples, not as a complete, independently buildable Android project.
